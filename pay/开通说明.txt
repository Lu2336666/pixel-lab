像素风 · 支付宝 2.88 终身解锁

一、这件事必须先办（否则无法「付完自动解锁」）
个人收款码、收款海报没有官方回调，网站不知道谁付了钱。
要用支付宝「手机网站支付」，付完才会通知服务器自动解锁。

你需要：
1. 支付宝账号（个人也可以申请；有个体工商户执照额度更高）
2. 网站域名 ICP 备案（github.io 不能备案。要买自己的域名，并把网站放到国内服务器或已备案域名）
3. 打开 https://open.alipay.com 创建「网页/移动应用」
4. 签约产品：手机网站支付
5. 在应用里设置接口加签方式 RSA2，下载应用私钥，把「支付宝公钥」复制下来

二、部署收款服务（Cloudflare Worker，免费）
电脑安装 Node 后，在本目录执行：

  cd pay
  npx wrangler login
  npx wrangler kv namespace create LICENSES

把打印出来的 id 填进 wrangler.toml 的 kv_namespaces。

  npx wrangler secret put ALIPAY_APP_ID
  npx wrangler secret put ALIPAY_PRIVATE_KEY
  npx wrangler secret put ALIPAY_PUBLIC_KEY
  npx wrangler deploy

记下地址，例如 https://pixel-lab-pay.你的账号.workers.dev

三、接到网站上
pay-config.js 里的 api 先留空时，网站仍可免费使用（避免你自己被锁住）。
填上 Worker 地址并发布后，没付款就进不去。改成：

  window.PIXEL_PAY = {
    api: 'https://pixel-lab-pay.你的账号.workers.dev',
    price: '2.88',
  };

支付宝开放平台里把授权回调/网关白名单带上这个 Worker 域名。
wrangler.toml 里 SITE_URL 改成你真正给用户打开的网址。

四、用户怎么用
没付款：整页挡住，不能选图。
点「支付宝支付 ¥2.88」→ 跳转支付宝 → 付完回到网站自动终身解锁。
换手机：点「我已付款」，填付款后的终身凭证 PX-xxxx-xxxxxx。

五、钱到哪里
进你签约的支付宝商户账户，费率大约 0.6%。2.88 实际到账约 2.86。
